# Virtual Office App

This repository contains the codebase for the Virtual Office App, organized into the following main folders:

## Folders

### `client`

- **Description:** The frontend application built with [Next.js](https://nextjs.org/).
- **Location:** `./client`
- **Details:** Contains all React components, pages, hooks, and services for the user interface.

### `server`

- **Description:** Supabase backend configuration and migrations.
- **Location:** `./server`
- **Details:** Contains Supabase configuration, database migrations, and environment setup for the backend.

### `sql-functions`

- **Description:** Supabase SQL functions and scripts.
- **Location:** `./sql-functions`
- **Details:** Contains custom SQL functions, triggers, and procedures used by the Supabase backend.

### `test`

- **Description:** Automated tests using [Vitest](https://vitest.dev/).
- **Location:** `./test`
- **Details:** Contains unit and integration tests for both frontend and backend logic.
